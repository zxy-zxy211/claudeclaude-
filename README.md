# 银柴火 · 编导 AI 化工作台

把《银柴火·编导 AI 化工作 SOP v1》做成两种能直接用的东西，**规则只有一份**：

| 用哪个 | 是什么 | 适合什么时候 |
|---|---|---|
| **三个技能** `.claude/skills/` | Claude 里说「写脚本」「改稿」「建博主卡」就自动按 SOP 走 | 平时在 Claude / Claude Code 里干活 |
| **网页工作台** `web/` | 本机跑的网页，接豆包（火山方舟）接口，确认关做成按钮 | 想用豆包、想要个顺手的界面 |

网页工作台的系统提示词**直接读 `.claude/skills/` 里的 SKILL.md**。改一次规则（比如加一条新雷区），两边同时生效，不会跑偏成两套。

## 一、三个技能

| 模块 | 目录 | 怎么触发 |
|---|---|---|
| 模块一 · 博主建档 | `.claude/skills/blogger-card/` | 「帮我建张博主卡」+ 贴 10-20 条作品 |
| 模块二 · 新稿生产 | `.claude/skills/script-draft/` | 「用这份逐字稿写条 3 分钟的观点稿」 |
| 模块三 · 内容修改 | `.claude/skills/script-revise/` | 「按这些意见改稿」+ 贴截图和全文 |

模块二额外带三份参考文件，写稿前会自己读：

- `references/hard-rules.md` —— 200 字/分钟、红线、删 AI 味。**新雷区就加在这里。**
- `references/frameworks.md` —— 五种题材骨架。
- `references/deliverables.md` —— 口播稿 / 分镜表 / 发布文案的格式。

博主卡存在 `bloggers/<博主名>.md`，照 `bloggers/_template.md` 建。

## 二、网页工作台

### 装一次

1. **装 Node.js**：去 https://nodejs.org 下 LTS 版，一路下一步（只用装这一个东西）。
2. **下载这个项目**：GitHub 页面 → 绿色 `Code` 按钮 → `Download ZIP` → 解压。
3. **双击启动**：Mac 双击 `启动-Mac.command`，Windows 双击 `启动-Windows.bat`。浏览器会自动打开。
4. **填 Key**：网页里点左下「设置」→ 粘贴火山方舟的 API Key 和模型名 → 「测试连接」→ 看到"连接正常"就成了。

Key 存在你这台电脑的浏览器里，不上传任何地方。也可以改走 `web/.env`（照 `web/.env.example` 复制一份填），那样浏览器完全不碰 Key。

零依赖，不用 npm install。端口 5173 被占用会自动顺延到 5174。
命令行启动也行：`node web/server.js`（加 `OPEN=0` 不自动开浏览器）。

模型填火山方舟控制台里实际可用的那个（模型名或 `ep-` 接入点 ID）—— 豆包型号会更新，别照抄任何文档里的例子。

### 四个页面

- **新稿生产**：填工单 → 出策划案 → **⛔确认关①做成按钮**（OK / 按我说的改）→ 开头策略 → **⛔确认关②** → 四段式成稿。右上角实时显示口播字数和折算分钟，偏离目标时长 15% 会变红。商单资料和对标参考各有自己的上传区；文件也能直接拖进逐字稿框，自动读成文字。
- **内容修改**：贴意见（**支持截图**，豆包直接读原话）+ 脚本全文 → 完整改稿 + 逐条核对表；勾「单段模式」就只改那一段。
- **博主卡库**：贴 10-20 条作品让 AI 建卡，改完保存进 `bloggers/`，写稿时自动带上。
- **流程 SOP**：`docs/SOP.md` 的在线版。

**能直接丢进去的东西**：

| 格式 | 怎么处理 |
|---|---|
| PDF | 内置 pdf.js 提取文字（含中文），离线可用 |
| Word `.docx` / PPT `.pptx` | 服务端自己解 zip 取正文，零依赖 |
| `.txt` `.md` `.csv` `.json` | 直接读 |
| 图片 / 截图 | 走豆包视觉，能读图上的字 |

读不了的：**网页链接**（接口不带联网，小红书还要登录）、**扫描件 PDF**（里面是图不是字，改用截图）、老格式 `.doc/.ppt`（先另存为新格式）。
视频要逐字稿：用剪映/飞书妙记转写后贴文本，比逐帧截图省得多。

## 三、想在别的 AI 里用

把对应 `SKILL.md` 的正文整段复制过去当系统提示词即可 —— 网页工作台做的就是这件事。

## 四、维护

跑通一稿发现新雷区 / 新口头禅：

1. 通用的 → 写进 `.claude/skills/script-draft/references/hard-rules.md`
2. 只针对某个博主的 → 写进 `bloggers/<博主名>.md`

技能、网页、SOP 文档三边同时更新，不用再各改一遍。
