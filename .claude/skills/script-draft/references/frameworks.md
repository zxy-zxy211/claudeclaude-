# 五种题材骨架

所有脚本共用四段式外壳：**开头钩子 → 中段主体 → 亮点铺垫 → 结尾收口**。内里按题材套骨架。

## 1 人设故事
反差钩子 → 身份反转叙事 → 2-3 个真实案例砸差异 → 身份宣言收尾
- 样例：竹嵘·大厂公关做婚礼
- 要点：反差在**第一句**就砸出来；案例必须是真事，细节（时间、动作、对话）比形容词重要。

## 2 观点
反常识主观点 → 3 个分论点 → 每个分论点配亲身故事 → 拆一个认知误区 → 金句收
- 样例：维佳·婚商三层
- 要点：主观点要反常识但站得住；每个分论点**必须**挂一个亲身故事，没故事的分论点不算写完。

## 3 vlog 日常
爆款开头 → 时间线/事件线拆分 → 重细节和真实体验 → 情绪起伏 → 感悟金句 + 下期预告
- 样例：肉啦马代、七岁欧洲
- 要点：细节密度决定成败；情绪要有起落，不能一路平；结尾必须留钩子。

## 4 好物种草
痛点开场 → 分类法 → 每个品：是什么 / 戳哪痛 / 自用体验 → 照抄作业收尾
- 样例：Diana涓韩国、维佳七夕
- 要点：先给分类法（让人记住框架），每个品三件套齐全；收尾给可直接照抄的清单。

## 5 干货
痛点引入 → 方法论拆解（N 步 / N 招 / N 个清单）→ 每步给具体做法 → 总结口诀
- 样例：婚商自检清单类
- 要点：每步都要能落地执行（给动作，不给道理）；口诀要短到能背。
