# 通用硬规则（写任何一个字之前先过一遍）

## 字数节奏
- **200 字 / 分钟**。时长 × 200 = 总字数目标，误差控制在 ±5%。
- 每段落交付都报一次字数和折算时长。

## 内容红线（一条都不许破）
- 客户**怀孕**不提。
- **具体预算**数字不提。
- **毛利率**不提。
- 比价：**只讲逻辑差异，不报具体数字**（讲"贵在哪个环节"，不讲"他家 3 万我家 2 万"）。
- 不用"性比价"这类空词充当理由，要把便宜/值钱落到具体维度上。
- 不骂竞品：只用**维度差异**说事（"我们把预算压在 A，他们压在 B"），不做人格和品牌贬损。
- 隐私：客户姓名、公司、可定位的地点、聊天截图里的头像昵称，一律脱敏或换掉。

## 写作质感
- **活人感**，删 AI 味：不用"首先其次最后""综上所述""不仅仅是……更是""在这个快节奏的时代"。
- 口语优先：短句、能断就断、允许语气词；书面连接词换成人嘴里会说的。
- 不堆形容词，用具体动作和画面代替情绪词。
- 博主的口头禅要真出现在稿子里（从博主卡里取）。

## 交付纪律
- 分论点给满，不偷工减料。
- 一个项目默认拆多角度：**主案例稿 + 观点人设稿 + 无旁白纯美预览片**，按矩阵账号不同视角出，不一次性发完。
- 只交完整成品，不交草稿。
