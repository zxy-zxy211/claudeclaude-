# 交付格式

## ① 口播稿（纯文案）
纯可念文案，按四段式分小标题（【钩子】【主体】【亮点】【收口】），每段末尾标 `（约 XX 字 / XX 秒）`。
不含镜头描述、不含花字、不含任何括号注释以外的导演说明。

## ② 分镜表
表格，五列固定：

| 镜号 | 时长 | 画面 | 口播 | 花字 |
|---|---|---|---|---|
| 01 | 3s | 具体画面（谁 / 在哪 / 做什么 / 景别） | 对应口播原文 | 屏幕文字 |

- 画面写**可拍**的东西：景别 + 动作 + 场景，不写"氛围感画面"。
- 口播列的文字加起来必须等于口播稿全文。
- 时长加起来等于目标时长。

## ③ 发布文案
- 标题：3 个备选，每个 ≤ 20 字，带钩子。
- 正文：小红书体（短段 + 换行 + 少量 emoji，不刷屏），不复述口播稿全文。
- TAG：8-12 个，赛道词 + 场景词 + 长尾词混搭。

## ④ 落飞书
按现有「银柴火·脚本」模板 7 段式写入：基础信息 / 大纲 / 分镜表 / 文案稿 / 修改意见 / 定稿表。
